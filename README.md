# Scoop bucket for EnvRune

[EnvRune](https://github.com/YagoLagrottiBracco/envrune) keeps environment
variables encrypted and gives them to the commands that need them.

```powershell
scoop bucket add envrune https://github.com/YagoLagrottiBracco/scoop-bucket
scoop install envrune
```

`envrune.json` is written by EnvRune's release workflow; changes made here
are replaced by the next release.
